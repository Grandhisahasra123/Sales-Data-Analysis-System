## Project Description

A Python-based Sales Data Analysis System that analyzes the
Superstore Sales Dataset to identify sales, profit, regional,
product, and time-based patterns.

## Dataset

- Superstore Sales Dataset
- Source: Kaggle
- Format: CSV
- Records: 9,994
- Columns: 21

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Analysis Performed

- Data preprocessing and validation
- Region-wise and product-wise GroupBy analysis
- Sales aggregation
- Sales trend analysis
- Sales distribution analysis
- Profit analysis
- Loss-making sub-category analysis
- Basic sales forecasting

## Project Files

- `Batch_15.ipynb` – Project code and analysis
- `Superstore.csv` – Dataset
- `requirements.txt` – Required Python libraries

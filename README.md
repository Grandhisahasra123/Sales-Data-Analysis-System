# Sales Data Analysis System

## Problem Statement

Raw sales data does not clearly show which products, categories, and regions perform well. It is difficult to identify sales trends, patterns, and areas of low performance.

This project analyzes and visualizes the sales data to identify important sales, profit, product, category, and regional patterns.
